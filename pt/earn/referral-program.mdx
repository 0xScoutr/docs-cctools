## Como funcionam as referências

Compartilhe seu código de referência exclusivo (formato: `CC-XXXXXX`) com amigos. Quando eles se inscrevem usando seu código, a indicação entra no status **pendente**.

O usuário indicado deve então completar **todas as 5 tarefas obrigatórias** para confirmar a indicação:

1. **Siga @cantontools** no X
2. **Mantenha uma sequência diária de 2 dias**
3. **Adicione uma carteira** ao portfólio
4. **Votar positivamente em 3 projetos de ecossistema**
5. **Mostre interesse em 3 oportunidades de ganho**

Cada tarefa concede XP. Assim que todas as tarefas forem concluídas e o usuário indicado atingir o **Nível 4**, a indicação será confirmada.

## Recompensas XP

- **Usuário indicado** recebe bônus XP imediatamente ao se inscrever com um código
- **Referenciador** recebe XP quando a indicação é totalmente confirmada (todas as tarefas concluídas + Nível 4)

Os selos de indicação são concedidos conforme você atinge os marcos de indicação.

## Regras

- Qualquer pessoa pode compartilhar um código de indicação; não há exigência de nível para ter um. O **Nível 4 vale para quem você convida**, e apenas para confirmar a indicação
- O usuário indicado deve completar **todas as 5 tarefas** (não apenas uma)
- Sem referências próprias ou contas falsas
- Os códigos de referência não podem ser reutilizados por outro usuário

Temos sistemas antiabuso em vigor para garantir encaminhamentos justos.
