## 1. Entre na sua conta

Abra [cctools.network](https://cctools.network) e entre na sua conta (ou crie
uma).

## 2. Abra o painel do desenvolvedor

Acesse [cctools.network/profile/api](https://cctools.network/profile/api).

## 3. Consiga um plano e uma chave

Uma chave precisa de um plano na sua conta. O painel de planos dessa página mostra
o que você pode assumir:

- **Pro**: uma assinatura do [CCTools Pro](https://cctools.network/pro) inclui
  acesso à API para uso pessoal, com 60 requisições por minuto em cada endpoint
  e 1.000 chamadas por dia. O cartão do Pro concede o acesso na hora
  (**Unlock Pro access**).
- **Teste**: **Start the trial** se você quiser experimentar a API primeiro. Fica
  disponível uma vez por conta, para contas com uma carteira conectada que passam
  na verificação de pessoa real do CCTools, somente para testes, com 60
  requisições por minuto e 1.000 chamadas por dia.
- **Data Starter ou Data Team**: para um produto ou serviço que mostra os dados a
  outras pessoas. **Buy Data Starter** ou **Buy Data Team** e pague em Canton
  Coin. O Data Starter permite 120 requisições por minuto e 20.000 chamadas por
  dia; o Data Team permite 600 requisições por minuto e não tem limite diário. Os
  preços estão em [Planos e limites](/pt/api/plans), e os termos em
  [cctools.network/terms/api](https://cctools.network/terms/api).
- **Validator**: envie o party ID do seu validador na Canton. Cada envio é
  revisado por uma pessoa, normalmente em até um dia útil. As chaves aprovadas
  não têm limite de requisições por chave e são gratuitas por 12 meses.
- **Construtor / fundo / parceiro**: preencha o formulário curto e conte o que
  você está construindo, ou [fale conosco](https://cctools.network/contact) sobre
  o Enterprise. Limites maiores são definidos por conta.

Um teto de 600 requisições por minuto por endereço IP vale em todos os planos.

Com um plano na sua conta, clique em **New key**. A chave em texto puro
(`cck_…`) é exibida **uma única vez**. Copie e guarde em um lugar seguro: você
não consegue vê-la de novo, apenas revogá-la e gerar uma nova.

<Warning>
Nunca exponha uma chave em código do lado do cliente. Faça as chamadas por um servidor
que você controla. Quem tem a sua chave pode chamar a API como você, até o seu limite de requisições.
</Warning>

## 4. Faça sua primeira chamada

```bash
curl -H "X-API-Key: cck_your_key_here" \
  "https://api.cctools.network/api/v1/public/ecosystem/projects?limit=5"
```

Você deve receber de volta um envelope JSON:

```json
{
  "data": [ { "slug": "…", "name": "…", "ai_score": 87 } ],
  "pagination": { "limit": 5, "offset": 0, "total": 491 },
  "meta": { "tier": "pro", "rate_limit_remaining": 60, "daily_limit_remaining": 999 }
}
```

É só isso. Veja todas as rotas na [referência de endpoints](/pt/api/endpoints), ou
rode uma com a sua chave direto no navegador em
[cctools.network/api-docs](https://cctools.network/api-docs).

<Tip>
Testar com `curl`, `python-requests` ou qualquer cliente padrão funciona de
imediato, desde que o header `X-API-Key` esteja presente. Requisições sem chave
vindas de clientes de ferramentas são bloqueadas; requisições com chave, não.
</Tip>
