Os 48 endpoints ficam sob `https://api.cctools.network`, devolvem o
envelope padrão `{ data, pagination, meta }` e exigem o header
`X-API-Key`. A única exceção é `/api/v1/public/status`, que não precisa de
chave e responde direto com o payload.

Os endpoints de listagem aceitam `?limit=` e `?offset=`. O formato comum é
padrão de 50 e máximo de 200, mas várias listas têm teto menor (50 ou 100) e
algumas ignoram `limit` por completo. Leia o `limit` devolvido em
`pagination` em vez de supor. Um valor fora da faixa aceita é ajustado em
silêncio para o valor válido mais próximo; nunca retorna erro.

`pagination.total` é o total real na maioria das listas. Em `/news` e
`/markets/tokens` ele é apenas o tamanho da página que você recebeu, então
pagine até receber menos itens que o seu `limit` em vez de comparar com
`total`.

<Note>
Troque `cck_...` por uma das suas chaves em
[/profile/api](https://cctools.network/profile/api). Existe um explorador
interativo com botão de envio ao vivo em
[cctools.network/api-docs](https://cctools.network/api-docs).
</Note>

<Warning>
**Cache frio.** A maioria dos endpoints servidos por um cache aquecido por cron
responde `503` com o código `warming_up` em vez de devolver um corpo vazio.
Trate isso como nova tentativa, não como resultado vazio. Três se comportam de
outro jeito e vale saber antes de construir em cima deles: `/governance` e
`/network/stats` respondem `200` com campos nulos ou zerados, e
`/featured-apps/{slug}` responde `404`, indistinguível de um slug que não
existe.
</Warning>

<Warning>
**Existe um teto por IP além do limite da sua chave.** Toda requisição a
`/api/`, em todos os tiers incluindo o Validator, conta contra um teto de 600
requisições por minuto por endereço IP. Excessos sustentados escalam para um
bloqueio temporário do IP, então recue quando vir um `429` em vez de tentar de
novo na hora. Se você precisa de um teto maior para uma carga histórica, avise
antes de rodar.
</Warning>

<Note>
A coluna Uso diz se os dados do endpoint podem ser usados em um produto comercial (Planos Data) ou são para uso pessoal, e a coluna Fonte de onde vêm. Os planos e seus limites estão em [Planos e limites](/pt/api/plans).
</Note>

## Ecossistema

Projects, categories, rankings, trending.

| Endpoint | Descrição | Uso | Fonte |
|---|---|---|---|
| `GET /api/v1/public/ecosystem/categories` | List categories with counts | Planos Data | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects` | List projects | Planos Data | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects/{slug}` | Get project by slug | Planos Data | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects/{slug}/analytics` | Engagement analytics for a project | Uso pessoal | CCTools engagement analytics |
| `GET /api/v1/public/ecosystem/projects/{slug}/campaigns` | Project campaigns | Planos Data | CCTools ecosystem directory |

| `GET /api/v1/public/ecosystem/rankings` | Projects ranked by metric | Planos Data | CCTools ecosystem directory, ranked by upvotes, views and clicks |
| `GET /api/v1/public/ecosystem/trending` | Top 20 trending projects this epoch | Planos Data | CCTools ecosystem directory, scored from upvotes, views and clicks |

```bash
curl -H "X-API-Key: cck_..." \
  "https://api.cctools.network/api/v1/public/ecosystem/categories"
```
