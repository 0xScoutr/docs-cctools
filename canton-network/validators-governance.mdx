## Validators Page

The **Validators** page lists all active validators on the Canton Network. For each validator you can see:

- Validator name and identity
- Role (Super Validator or regular Validator)
- Performance metrics and rewards data

**Pro users** get access to additional validator data and export options.

## Super Validators

Super Validators are major financial institutions that validate transactions and have additional governance rights:

- Voting on protocol changes and network parameters
- Proposing network upgrades
- Setting fee structures

Examples include major banks and financial institutions that participate in the Canton Network consortium.

## Governance

CCTools tracks all governance activity on the **Governance** page:

- Active and past proposals
- Voting status and results
- Super Validator participation
- Approval rate and execution status
- Network parameter changes

This gives the community full transparency into how the network is governed.
