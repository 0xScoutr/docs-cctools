Markets 是你探索 Canton 生态系统的一站式中心。在七个标签页之间切换，发现实时的 DeFi 机会、代币化资产、带价格数据的代币，以及如何获取 Canton Coin (CC)。

## DeFi 资金池

来自 Canton 原生 DEX 协议的实时流动性资金池：Tradecraft、Send、Cantex、OneSwap 和 Silvana。

**你会看到**
- 资金池交易对（例如 CC/USDT）和协议名称
- 来自协议的总锁仓价值 (TVL)
- 14 天交易量
- 年化收益率 (APR) 或 APY 区间（来自 Tradecraft/Send 的实时数据，其他协议在其 API 上线前为硬编码值）

**筛选**
- **协议**：缩小到 Tradecraft、Cantex、OneSwap 或 Send。默认全部。
- **搜索**：输入资金池交易对名称或协议 slug。

**排序选项**
- 最高 APR（默认）
- 最高 TVL
- 最高 14 天交易量

所有资金池数据通过 Tradecraft 和 Send 端点实时更新（5 分钟缓存）。点击资金池行查看该协议的生态系统页面，或点击 Open 直接在该协议的界面上进行存款。

## RWA（真实世界资产）

Canton 上的代币化真实世界资产：大宗商品、BTC、指数等。Temple 的订单簿市场作为权威的 RWA 场所出现在此处。

**你会看到**
- 资产发行方和项目名称
- 类别：大宗商品、BTC、指数
- 覆盖范围描述（例如"金条，实物存储"）
- 状态：上线 或 筹备中（即将推出）

**筛选**
- **类别**：大宗商品、BTC、指数，或全部
- **搜索**：输入发行方或资产名称

**排序选项**
- 上线优先（默认，筹备中的资产会淡化显示）
- 名称 A-Z

每个 RWA 发行方都会显示一个 Open 按钮以在 Temple 上交易，或显示 Details 以阅读完整的项目简介。

## 稳定币

在 Canton 上线或锚定的稳定币，分为上线和即将推出两个部分。

**你会看到**
- 稳定币名称、代号和发行方
- 类型：法币支持、生息型、加密支持、MMF
- 锚定目标（例如 USD、EUR）
- 状态：上线 或 即将推出

**筛选**
- **类型**：法币支持、生息型、加密支持、MMF
- **搜索**：名称、代号或发行方

**排序选项**
- 名称 A-Z（默认）
- 按类型
- 多链优先

多链稳定币会被标记，以便你知道哪些是 Canton 原生的，哪些是从其他链通过 bridge 引入的。

## 代币

带有代币的 Canton 生态系统项目，合并自两个来源：
- 数据库中的 Canton 生态系统项目（带有简介页面的真实项目）
- CoinGecko 实时市场数据（价格、市值、24 小时变动）

**你会看到**
- 代币名称和代号
- 项目（发行方）
- 智能合约地址（可复制，或对于尚未在本地索引的仅来自 CoinGecko 的条目为空）
- 当前价格
- 市值（带有稀有度徽章：普通、罕见、稀有、史诗、传奇）
- 24 小时价格变动（上涨为绿色，下跌为暗灰色）

**筛选**
- **链**：Canton、Base、BSC、Ethereum，或全部
- **搜索**：代币名称、项目名称或代号

**排序选项**
- 最高市值（默认）
- 最高价格
- 最大 24 小时变动
- 名称 A-Z

点击代币行查看其生态系统简介或网站。数据从 CoinGecko 实时刷新；在数据库中但尚未在 CoinGecko 上的代币会显示价格为空。

## 获取 CC

如何获取 Canton Coin (CC)。找到最适合你所在地区、交易所类型和 KYC 偏好的路径。

**你会看到**
- CC 价格和 24 小时变动（顶部主卡片）
- 市值和 24 小时交易量
- 所有场所按 CC 交易量排名

**对于每个场所**
- 类型：DEX 或 CEX
- Maker 费用（如已列出）
- KYC 要求：无（绿色盾牌）、可选（琥珀色）或必需（灰色）
- 该场所的实时 CC 价格
- 24 小时 CC 交易量

**筛选**
- **国家/地区**：任何地方、美国、欧盟、英国、巴西、越南、印度尼西亚、尼日利亚
- **类型**：所有场所、仅 DEX、仅 CEX
- **KYC**：任何级别 或 无 / 可选
- **搜索**：场所名称

**排序选项**
- 最高 24 小时交易量（默认，仅 CEX）
- 最低 Maker 费用
- 无 KYC 优先
- 最多法币交易对

没有实时 CC 交易量的 CEX 场所会被隐藏（无噪音）。无论交易量如何，DEX 路径始终显示。点击 Open 在该场所交易，或 Details 查看完整的交易所简介。底部的提示说明从其他链到 Canton 的 bridge 路径即将推出。

## Bridge

进入 Canton 的跨链路径。哪些资产通过 bridge 进入，来自哪些源链，通过哪些协议。

**你会看到**
- Bridge 名称和协议
- 路径：从 Bitcoin、Ethereum、Base 或 多链 到 Canton
- 通过 bridge 转移的资产（例如 BTC、ETH、USDC）
- 证明类型或标准（例如"轻客户端"、"MPC"）
- 状态：上线 或 即将推出

**筛选**
- **路径**：全部、从 Bitcoin、从 Ethereum、从 Base、多链
- **搜索**：Bridge 或资产名称

**排序选项**
- 上线优先（默认，筹备中的 bridge 会淡化显示）
- 名称 A-Z

点击 Open 访问 bridge 界面，或 Details 查看 bridge 协议的生态系统简介。

## Wallet

自托管 wallet、硬件 wallet 以及机构/OTC 解决方案。分为三个层级：零售、硬件（冷存储）以及机构与 OTC（托管 + 做市商）。

**你会看到**
- Wallet 名称
- 平台：浏览器、Web、移动端、硬件、托管 或 多平台
- 托管类型：自托管 或 托管
- KYC 要求：无（绿色）或 必需（灰色）

**筛选**
- **托管**：全部、仅自托管、仅托管
- **KYC**：任何级别 或 无 KYC
- **搜索**：Wallet 名称

没有排序选项（按层级排序：零售、硬件，然后是机构/OTC）。点击 Open 访问 wallet，或 Details 查看其生态系统页面。

## 筛选和搜索

每个标签页顶部都包含一个筛选栏。

**搜索** 会根据标签页的不同，匹配资金池交易对、协议名称、发行方名称、资产名称、代币代号、项目名称和场所名称。

如果你的搜索没有返回结果，点击空状态按钮来**重置筛选**。

**桌面端 vs. 移动端**：在桌面端，所有筛选和排序控件出现在一个水平栏中。在移动端，搜索首先出现；筛选和排序在下方堆叠为 2 列网格。

## 实时数据

大多数数据实时更新：
- **DeFi 资金池**：Tradecraft 和 Send 的交易量/APR 通过 API 刷新（5 分钟缓存）
- **代币**：来自 CoinGecko 的价格、市值和 24 小时变动（实时）
- **获取 CC**：来自 CoinGecko tickers 端点的 CC 价格主卡片和各场所价格（实时）
- **RWA、稳定币、Bridge、Wallet**：手动更新的精选静态列表

## 首次使用导览

在你首次访问 Markets 时（或如果你清除了 localStorage），coachmark 导览会高亮标签栏、筛选栏和资金池表格。它对每位用户显示一次，并可被关闭。
