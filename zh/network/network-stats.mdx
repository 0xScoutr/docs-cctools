## 概述

**网络统计**页面显示有关 Canton Network 的实时和历史数据：

- **CC 价格** - 当前价格、24 小时变化、市值和交易量
- **验证者** - 超级验证者和常规验证者的总数
- **燃烧/铸币比率** - 网络当前是否处于通货紧缩状态（燃烧数量多于铸币数量）
- **每日交易** - 网络上的交易量
- **治理** - 提案总数、批准率、执行与拒绝
- **发行率** - 每个超级验证者、验证者和应用优惠券利率
- **TradingView 图表** - 实时 KRAKEN:CCUSD 价格图表，具有完整的 TradingView 集成

## 烧伤与薄荷

CCTools 跟踪 CC 代币每小时的销毁和铸造数据：

- **燃烧** - CC 代币作为交易费用被燃烧
- **Mints** - CC 代币作为验证者奖励而铸造
- **比率** - 当比率高于 1.0 时，燃烧的 CC 多于铸造的 CC（通货紧缩）

该数据以双条形图显示，涵盖过去 24-72 小时，帮助您实时了解代币的供应动态。
