一个实时映射 Canton 生态系统参与者的交互式网络可视化。Canton 地图将项目、验证者、精选应用和活动显示为相互连接的节点，用边表示它们之间的关系。

## 打开地图

访问 Canton 地图页面，并从网格中选择一个类别（金融、基础设施、社交等）。地图仅加载该类别的子图，无论网络规模多大都能保持快速性能。

每个类别显示：
- **项目** - 实心彩色圆圈，按类别颜色分组（DeFi 为蓝色，Trading 为琥珀色，等等）
- **验证者和超级验证者** - 在链上保护项目的环形节点
- **精选应用** - 构建在选定项目之上的应用
- **Earn 列表** - 该类别内可用的机会
- **活动** - 进行中的推广和事件

## 解读图谱

**节点类型**（在图例中显示）：

- **项目** - 带有你所在类别颜色的实心圆圈
- **类别枢纽** - 空心灰色环（显示某一类别内的项目）
- **验证者** - 空心蓝色环（验证一个或多个项目）
- **超级验证者** - 空心琥珀色环（经 DSO 批准的超级验证者节点）
- **精选应用** - 实心紫色圆圈（构建在某个项目之上的应用）
- **Earn 列表** - 实心绿色圆圈（付费机会）
- **活动** - 实心紫色圆圈（限时推广）

项目节点上的**视觉叠加层**：
- 小型**精选应用徽章**（紫色闪光） - 拥有精选应用
- **赞助徽章**（琥珀色闪电） - 已被赞助
- **验证者徽章**（绿色六边形） - 至少拥有一个验证者
- **SV 徽章**（琥珀色六边形） - 至少拥有一个超级验证者

**连接**显示关系：
- 项目归属于类别（向上的边）
- 验证者和超级验证者保护项目（入向的边）
- 精选应用由项目驱动（出向的边）
- 项目承载 Earn 列表和活动

## 与地图交互

**平移** - 点击并拖动以在图谱中移动。

**缩放** - 向上滚动以放大，向下滚动以缩小。使用右下角的缩放按钮进行更精细的控制。

**搜索** - 顶部的搜索栏可按名称或 ID 查找任何项目、验证者或应用。结果会显示在下拉菜单中，并支持键盘导航：
- 向上 / 向下箭头键切换选择
- Enter 键跳转到某个节点
- Escape 键关闭

当你搜索另一个类别中的节点时，地图会自动切换到该类别并聚焦该节点。

**点击节点** - 在右侧（桌面端）打开其详情面板，或以底部抽屉（移动端）形式打开。该面板显示：
- 名称、徽标和类别
- 相关节点（关联的项目、验证者、应用、机会、活动）
- 评分和指标（如果可用）
- 指向外部资源的链接

**筛选节点类型** - 使用筛选按钮开启或关闭验证者、超级验证者、精选应用、Earn 列表或活动。按钮上的徽章显示当前有多少个筛选条件处于激活状态。

**缩放控件**（右下角）：
- 放大 / 缩小 - 按步长调整比例
- 重置视图 - 返回默认的缩放和位置
- 重新加热模拟 - 重启力学物理，当节点堆积在某个角落时很有用

## 桌面端与移动端

**桌面端**：图例侧边栏（220px）出现在左侧，包含节点类型说明、视觉叠加层和类别按钮。隐藏它可以扩大画布。节点详情面板停靠在右侧。

**移动端**：点击筛选按钮（在搜索栏左侧）即可在底部抽屉中打开图例和类别选择器。选择某个节点时，详情面板会从底部向上滑出。

## 理解布局

该图谱使用力导向模拟，它会：
- 排斥重叠的节点（碰撞）
- 将相连的节点相互吸引
- 按节点之间的关系对其进行聚类

节点会在 60-120 个时间刻内稳定成一个排列。如果布局看起来杂乱，点击重新加热模拟即可从头重启物理。拖动任何节点会暂时将其固定在原位；松开即可解除固定。

背景包含一个微妙的点阵网格和径向渐变，以在任何缩放级别下都保持画布的可读性。

## 性能

每个类别仅加载其子图（通常为 30-80 个节点），而非整个网络。地图使用 Canvas 渲染器和 Web Workers 进行模拟，即使在较旧的设备上也能保持 60 FPS。

- **类别选择器**约在 100ms 内加载图谱元数据
- **地图渲染**根据子图大小约在 200-500ms 内完成
- **模拟**在浏览器中运行；交互期间无需服务器往返

## 小贴士

- 如果你刚开始使用该地图，请**从一个较小的类别开始**。金融（DeFi）是最大的；服务或 DAO 则更为紧凑。
- **使用图例**来理解每种颜色和形状的含义。所有类别的视觉语法是一致的。
- **按项目名称搜索**可直接跳转到某个特定的生态系统参与者，然后探索出向的边以发现验证者和应用。
- **将光标悬停在节点上**即可在工具提示中查看其名称。点击可打开完整的详情面板。
- 通过搜索并点击不同类别中的节点，可**打开多个详情面板**。每个面板都会替换上一个。

## 后续步骤

从详情面板，你可以导航至：
- 项目的完整资料页面（如果它是一个项目）
- 同一地图上的相关项目、验证者或活动
- 参与生态系统的 Earn 机会
