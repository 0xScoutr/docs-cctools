## 什么是活动？

合作伙伴在 CCTools 上开展活动。每个活动页面都会说明其任务、奖励，以及谁可以领取兑换码或在抽奖中获奖。奖励可以是访问码、链接、抽奖资格或由合作伙伴发放的奖品，有些活动还会颁发活动徽章。

## Campaigns 页面

从顶部栏（会显示进行中活动的数量）或页脚打开 **Campaigns**：[cctools.network/earn](https://cctools.network/earn)。页面有两个标签页：**Active** 和 **Ended**。你可以按类型（**Access code**、**On-chain**、**Learn path**、**Social tasks** 和 **Partner offer**）缩小列表范围，或按名称或合作伙伴搜索。每一行都会以简短形式显示活动规则，例如 **Verified to win** 或 **Level 8+**。

兑换码活动会显示剩余的兑换码数量：

- **Plenty left** - 剩余超过一半
- **Some left** - 剩余五分之一到一半
- **Few left** - 剩余不到五分之一
- **Sold out** - 已无剩余

## 加入活动

1. 打开活动并阅读其 **Before you start** 卡片（即第 0 项任务）：它说明了谁可以参加的规则，以及该规则是在你加入时检查还是在抽奖进行时检查
2. 点击 **Join campaign**（未登录时显示 **Sign in to join**）
3. 以任意顺序完成任务。加入后，**Your progress** 会显示已完成的必做任务数量，可选任务会带有 **Optional** 标签
4. 接下来会发生什么取决于活动类型：
   - **兑换码或链接** 活动会在你最后一项必做任务通过核验时立即发放奖励，发完即止
   - **抽奖** 活动会在你完成所有必做任务后为你登记参与，并在活动结束后抽出获奖者

有些活动设有参与人数上限，所以请尽早加入以确保名额。你参加的活动及其状态和剩下要做的事情都在 **Profile > Activity > Campaigns** 中。关于规则和抽奖，请参阅 [获奖者如何产生](/zh/campaigns/how-winners-are-chosen)。

## 任务类型

- **Follow** - 在 X 上关注某个账户
- **Like + RT** - 在 X 上点赞并转发某条帖子
- **Post** - 在 X 上发布一条符合活动要求的帖子
- **Upvote** - 在项目目录中为合作伙伴的项目投票
- **Mark interest** - 对活动标记感兴趣
- **Visit** - 访问某个页面或网站
- **Join now** - 加入合作伙伴的 Discord 服务器或 Telegram 群组
- **Sign up** - 订阅合作伙伴的邮件列表
- **Star** - 为某个 GitHub 仓库加星
- **Verify** - 完成一条 Learn 路径，或在 Canton 上完成一次真实操作（兑换、交易、付费调用），并用你的 party id 通过合作伙伴的接口进行核验
- **Submit** - 提交活动要求的文本
- **Complete** - 合作伙伴定义的其他任务

需要核验账户的任务要求该账户已在 **Settings > Connected accounts** 中连接。为项目投票和标记感兴趣在 8 级开放，但你已加入的进行中活动允许你在任何等级为其自己的项目执行这两项操作。
