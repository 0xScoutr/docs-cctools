## 什么是营销活动？

活动是与 Canton 生态系统项目合作创建的赞助任务。每个活动都有一组任务需要完成，完成所有任务即可为您赢得 XP、徽章，有时还可以获得独家奖励（兑换代码、链接等）。

活动显示在**赚取**页面上，并标有合作伙伴项目的品牌。

## 加入活动

参加活动：

1. 转到 **赚取** 页面并找到正在进行的活动
2. 点击**加入**即可参与活动
3. 完成活动中的每项任务（可以按任意顺序完成）
4. 完成所有任务后，接下来会发生什么取决于活动类型

对于发放**兑换码或链接**的活动，最后一项必做任务通过验证的那一刻，奖励就会自动领取。而在**抽奖**活动中，此时不会领取任何东西：完成任务只是让您获得抽奖资格。活动结束且抽奖结果确认之后，只有当奖品是兑换码时，活动页面才会出现领取按钮。大多数抽奖奖品属于外部发放，也就是由合作方在平台之外交付（例如一笔链上付款），因此页面上没有任何东西需要领取。

有些活动有**参与者限制**，因此请尽早加入以确保您的席位。

## 任务类型

活动可以包括不同类型的任务：

- **关注 X** - 关注合作伙伴项目的 Twitter/X 帐户（需要 X 连接）
- **转发** - 转发特定帖子
- **在 X 发帖** - 发布符合活动要求的帖子（必须包含的提及、关键词、最短长度）
- **赞成项目** - 赞成生态系统目录中的合作伙伴项目
- **对赚取表现出兴趣** - 对合作伙伴的赚取机会表现出兴趣
- **访问 URL** - 访问特定页面或网站
- **加入 Discord** - 加入合作伙伴的 Discord 服务器
- **加入 Telegram** - 加入合作伙伴的 Telegram 群组或频道
- **邮件订阅** - 订阅合作伙伴项目的邮件列表
- **完成 Learn Path** - 在 CCTools 上完成一条 Learn Path
- **链上任务** - 在 Canton 上完成真实操作（一笔 swap、一笔交易、一次付费调用），并用您的 party ID 在合作伙伴的接口上完成验证
- **文本提交** - 提交文本（例如，您的 Discord ID、电子邮件等）
- **自定义任务** - 合作伙伴定义的其他任务

每个完成的任务都会获得 XP。完成活动中的**所有任务**也可能会奖励特殊徽章。
