## Guides 书架

**Guides** 位于 **Library** 菜单中，是 CCTools 的阅读书架，地址为 [cctools.network/academy](https://cctools.network/academy)。它收录关于 Canton 网络如何运作以及其生态项目的文章，并提供搜索和主题来缩小列表范围。

指南是用通俗语言写成、带有编号来源的解读文章，其中许多会在页面加载时显示从 CCTools 每日记录读取的数据，因此这些数据不会过时。指南会在发布后陆续加入书架；目前书架上收录的是文章。被某篇指南改写的文章会保留其位置和地址，直到该指南发布。

**Learn** 是 Library 的互动部分：按顺序排列的简短课程，每节课附带测验。参阅 [Learn](/zh/earn/learn-paths)。

## 阅读文章

每篇文章都在独立页面中打开，任何人无需登录即可阅读。页面显示：

- **Facts in this article**（如有）：每条事实都读取自其来源并注明日期，其编号指向文末对应的来源
- **On this page**，即目录，在宽屏上始终显示在正文旁边
- **Where to look next**，可能会指向相关的 Learn 课程
- **About this article**，说明作者是谁，并附有指向 Methodology 和 **Suggest a correction** 的链接
- **Share** 和 **Cite**

## 为 Library 撰稿

Library 不接受社区投稿。如果你有想写的主题或发现了错误，可以通过文章中的 **Suggest a correction**（它会打开 [Feedback](https://cctools.network/feedback)，需要达到 8 级）告诉我们，或在任意等级通过 [Contact](https://cctools.network/contact) 页面联系我们。
