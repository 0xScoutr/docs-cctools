## 加入 Discord

CCTools Discord 服务器面向所有社区成员开放。使用此邀请链接加入：

**https://discord.gg/Pm2YpafyxP**

你也可以通过 **cctools.network/discord** 访问此链接，获取一个简短、便于分享的 URL。

## 验证：表情挑战

首次加入时，完成表情选择验证码即可获得 **Verified** 身份组。这是一项快速的真人检查，类似于主站的注册防护：

- 运行 `/verify` 命令（或点击欢迎频道中常驻的 **Verify** 按钮）
- 会出现一个挑战，包含四个表情按钮以及指定目标的提示（例如 "Click the Apple"）
- 点击正确的表情按钮
- 你会在几秒内获得 **Verified** 身份组

该挑战在 5 分钟后过期。如果超时，只需再次运行 `/verify` 即可。这能证明你是真人，并解锁完整社区的访问权限。

## 关联你的 CCTools 账户

已验证的成员可以选择关联其 Discord 账户，以同步 XP 和平台活动：

- 运行 `/link` 命令（或点击常驻的 **Link Account** 按钮）
- 你会看到一个指向 CCTools OAuth 连接页面的链接
- 请先确保你已在浏览器中登录 **cctools.network**
- 点击该链接并授权 Discord 访问
- 你的 Discord 身份会在约 1 分钟内连接到你的 CCTools 账户

一个 CCTools 账户只能关联一个 Discord 账户。若要更换 Discord 账户，请先在 CCTools 的 **Profile > Connections** 页面解除当前账户的关联，然后用新的 Discord 账户再次运行 `/link`。

## Discord 参与：通过聊天赚取 XP

同时处于 **verified** 和 **linked** 状态的成员，会因其在聊天中的参与而获得 Discord 参与 XP。这是一个独立于你主平台 XP 的参与轨道：

- **Messages**：你发送的每条消息都会赚取参与 XP（设有每用户冷却时间和每日上限）
- **Reactions received**：当其他人对你的消息做出反应时，你会赚取参与 XP
- **Replies received**：对你消息的回复同样会给予参与 XP

聊天活动会被持续跟踪。你所赚取的参与 XP 每天上限为 300 XP，以防止刷量。

## 查看你的参与排名

使用 `/rank` 命令查看你的参与进度：

- **`/rank`**：查看按参与 XP 排名的前 10 名成员的全球排行榜
- **`/rank @user`**：查看某位特定成员的参与等级、消息数量、距离下一等级的进度以及已获得的徽章

排行榜是公开的（非临时显示），因此所有人都能看到成员的排名。你的排名会显示：

- **Level**：你的参与等级（根据累计参与 XP 计算）
- **Messages**：你在服务器中发送的消息总数
- **Progress**：通往下一参与等级的可视化进度条
- **Badges**：你已获得的里程碑徽章

## Discord 身份组与平台等级

你的 Discord 身份组会自动映射你在 CCTools 上的平台等级，并随着你的晋升而更新：

- Level 1-4: Newcomer
- Level 5-9: Explorer
- Level 10-14: Analyst
- Level 15-19: Strategist
- Level 20-24: Operator
- Level 25-29: Architect
- Level 30-34: Validator
- Level 35-39: Governor
- Level 40-44: Syndicate
- Level 45-50: Canton OG

身份组会在你关联账户时同步，并随着你在平台上赚取 XP 而自动更新。

## 徽章与平台 XP

Discord 参与里程碑会解锁徽章，授予少量平台 XP（在 cctools.network 上）：

- **Active Badge**（参与等级 5）：少量平台 XP 奖励
- **Regular Badge**（参与等级 10）：更大的平台 XP 奖励
- **Veteran Badge**（参与等级 15）：更高的奖励
- **Champion Badge**（参与等级 25）：最稀有的徽章，奖励最高

这些徽章在你每达成一个参与里程碑时仅可获得一次。由于徽章集合是有限的，你通过 Discord 参与所能赚取的平台 XP 总量上限为 300 XP。这一设计可防止用聊天活动来攀升主平台排行榜。相反，Discord 参与是一种有意义的方式，通过一次性的小额奖励来表彰活跃的社区成员。
