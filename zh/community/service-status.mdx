CCTools 公共 API 在 **status.cctools.network** 提供实时状态面板，你可以在此监控所有核心 endpoint 的健康状况和性能。

## 关于状态页面

状态页面是 CCTools 公共 API 的公开实时面板。它持续收集健康数据并自动更新：

- 页面每 30 秒刷新一次
- 每个 endpoint 大约每 2 分钟检查一次
- 历史数据涵盖最近一小时
- 最近事件显示过去 30 天的记录

## 你在状态页面上看到的内容

### 总体状态

在页面顶部，你将看到以以下三种状态之一显示的总体系统状态：

- **所有系统正常运行**：每个受监控的 endpoint 都健康
- **性能下降**：部分 endpoint 未完全健康，或存在正在进行的事件
- **重大中断**：大多数 endpoint 已宕机，或存在严重事件

### 各 endpoint 健康状况

状态页面显示按类别分组的受监控 endpoint 表格。对于每个 endpoint，你可以看到：

- 状态指示器（绿色表示运行正常，红色表示宕机）
- 上次检查时间（例如，"47 秒前"）
- 最近一次响应的 HTTP 状态码
- 最近一次检查的延迟（以毫秒为单位）
- 1 小时正常运行时间百分比
- 最近一小时的平均延迟
- 延迟迷你图（使用对数刻度显示最近一小时检查的可视化图表）

### 正在进行的事件

如果存在任何持续的问题，**正在进行的事件** 部分会出现在靠近顶部的位置。每张事件卡片显示：

- 事件标题和严重级别（次要、重大、严重或维护）
- 当前状态（调查中、已确认、监控中或已解决）
- 问题描述（如果可用）
- 受影响的 endpoint
- 事件开始的时间

### 近期事件历史

在 endpoint 下方，你会找到 **近期更新（过去 30 天）**，显示已解决的事件和过去的状态变更。这有助于你了解最近修复或更改了哪些内容。

## 受监控的 endpoint

状态页面监视 CCTools 公共 API 中的 11 个核心 endpoint：

**Meta**
- OpenAPI 规范（API 规范文档）

**Ecosystem**
- 列出项目
- 热门项目
- 项目类别
- 项目排名

**Users**
- 获取用户资料（使用测试用户账户）
- 用户徽章
- 用户贡献
- 用户活动

**Earn**
- 列出机会

**Leaderboard**
- Leaderboard 排名

每个 endpoint 都会单独探测，以确保你能够细致地了解哪些服务健康、哪些可能存在问题。

## 故障排除

如果你在使用 CCTools API 时遇到问题：

1. **首先查看状态页面**：访问 **status.cctools.network** 查看是否存在影响你的 endpoint 的已知事件
2. **查看正在进行的事件**：如果存在正在进行的事件，查看其状态和描述以了解问题及任何变通方法
3. **检查受影响的 endpoint**：事件卡片会显示哪些 endpoint 受到影响，以便你识别你的调用是否受到影响
4. **报告问题**：如果状态页面显示一切正常，但你仍然遇到问题，请通过 **Report an issue** 链接报告，或通过 **/contact** 联系我们
