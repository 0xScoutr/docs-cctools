## 赚取 XP

XP（经验点）是 CCTools 的核心参与度指标。您可以通过以下方式赚取 XP：

- **每日签到** - 每天登录即可通过里程碑奖金赚取连续 XP
- **投票项目** - 通过对生态系统项目投票赚取 XP（每日限制）
- **查看项目** - 通过探索生态系统赚取 XP
- **在 X 上关注 @cantontools** - 一次性 XP 奖励
- **添加钱包** - 用于连接您的投资组合的 XP
- **推荐朋友** - 当您的推荐人完成所有任务并达到 4 级时即可获得 XP
- **完成活动** - XP 因活动而异

**专业用户** 在所有操作中都会获得 **XP 乘数**。

## 每日重置和连胜

一些 XP 操作每天在 UTC 午夜重置：

- **每日签到** - 赚取基本 XP + 连续奖励
- **点赞** - 每天的点赞数量有限
- **项目视图** - View XP 每天重置

**连续里程碑** 在关键时间间隔（7、14、30、60、90、100、180 和 365 天）奖励奖励 XP 和专属徽章。您的连胜时间越长，奖励就越大。

缺席一天会重置您的连续记录，因此一致性是关键！

## 级别

您的总 XP 决定了您的等​​级（最高等级 50）。每个级别都有一个标题：

- **1-5级** - 新人
- **6-10级** - 探险家
- **11-15级** - 分析师
- **16-20级** - 战略家
- **21-25级** - 操作员
- **26-30级** - 建筑师
- **31-35级** - 验证者
- **36-40级** - 总督
- **41-45级** - 辛迪加
- **46-50 级** - 坎顿 OG

**4 级**是关键的里程碑：它解锁了投票、推荐和徽章资格。每个级别所需的经验值逐渐增加。
