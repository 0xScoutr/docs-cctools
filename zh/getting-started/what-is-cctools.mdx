## 概述

CCTools 是 Canton Network 的公共记录。它发布一份任何人都可以下载和引用的开放每日网络记录，收录在 Canton 上构建的项目，跟踪网络的市场与治理，并提供追踪你自己钱包的工具。

CCTools 上的数据都会说明来源，[Methodology](https://cctools.network/methodology) 页面解释了每项数据是如何收集的。

## 你可以做什么

**Network** - **Daily record**：按天记录的网络状态、发行量和供应量，读取自 Scan，每天一个可下载、可引用的开放文件。在它旁边还有：费用与轮次、超级验证者、按奖励排名的每个持牌验证者、下一次网络升级及已准备就绪的验证者数量、featured apps、治理提案以及奖励计算器。

**Ecosystem** - CCTools 收录的 Canton 项目目录，支持搜索和筛选，另有按领域分组的地图、本月新增的项目、分类、A 到 Z 列表、并排比较，以及与每个项目相关的新闻。任何人都可以提交目录中遗漏的项目。

**Markets** - 按 DefiLlama 报告的各协议 DeFi TVL、代币化资产、代币价格、稳定币、跨链桥、钱包与托管，以及获取 Canton Coin 的途径。

**Portfolio** - 在一个视图中查看你在 Canton、EVM 和 Solana 上的钱包及其余额，以及你的 CC 奖励和转账。**Party lookup** 可以只读方式打开任何 Canton party，无需登录。

**Library** - **Guides**（关于网络如何运作的文章）、**Learn**（按顺序排列的简短课程，每节课附带测验）以及更新日志 **What's new**。

**Developers** - 带有密钥和方案的公共 API、用于连接 AI 代理的 MCP 服务器、Methodology，以及汇集 SDK、工具和代码仓库的 **Build on Canton**。

**Campaigns** - 合作伙伴在 CCTools 上开展活动。每个活动页面都会说明其任务、奖励，以及谁可以领取兑换码或在抽奖中获奖。

**你的个人资料** - 获得 Verified、每天签到、关注你的 XP 和等级，并分享你的公开页面。

**Ask Synchro** - 本文档站点上的助手会根据 CCTools 文档回答问题。

## 适合谁使用？

- 需要可引用的 Canton Network 数据的 **研究人员、分析师和记者**
- 通过 API 读取网络数据的 **开发者和数据团队**
- 追踪钱包、奖励和网络规则的 **持有者和验证者**
- 希望在目录中被发现的 **项目方**
- 正在了解网络如何运作的 **新用户**
