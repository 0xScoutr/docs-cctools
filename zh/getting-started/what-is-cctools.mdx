## 概述

CCTools 是 Canton Network 生态系统领先的多功能工具平台。它提供了您跟踪投资组合、发现项目、赚取奖励、监控网络统计数据以及了解 Canton 生态系统最新动态所需的一切。

无论您是 DeFi 用户、验证者，还是刚刚开始使用 Canton，CCTools 都可以为您提供一个仪表板来管理这一切。

## 主要特点

**投资组合追踪器** - 连接您的钱包并查看您的完整 Canton 投资组合以及实时价格、损益、奖励和转账历史记录。

**生态系统目录** - 浏览在 Canton Network 上构建的数百个项目，可按类别、角色和状态进行过滤。为你最喜欢的投票点赞。

**探索** - 统一的发现中心，并排显示项目、验证器和奖励。

**比较** - 并排比较最多 4 个项目（专业版）或验证器。

**赚取** - 完成任务、发现机会并参加活动以赚取 XP 并登上排行榜。

**学院** - 阅读社区撰写的关于 Canton 和 CCTools 的精选文章和实践指南。通过帖子提交流程发布您自己的内容。

**新闻** - 以广州为中心的新闻源，包含法学硕士摘要，以及成员提交帖子的社区源。搜索、过滤和订阅新内容通知。

**学习路径** - 多步骤结构化学习轨道，指导您完成 Canton、CCTools 和相关主题。

**奖励计算器** - 计算作为应用程序构建者、验证者或 CC 持有者的潜在奖励。

**网络统计** - 与 TradingView 集成的实时 Canton 网络指标。

**治理** - 跟踪超级验证者投票和治理提案。

**排行榜** - 通过标准视图、每周视图和分组视图查看您在其他 CCTools 用户中的排名。

## 它是给谁用的？

CCTools 设计用于：

- **新用户**首次探索Canton Network
- **DeFi 用户**跟踪 Canton 应用程序中的投资组合表现
- **社区成员**通过参与赚取 XP 和徽章
- **项目团队**通过赞助列表寻找知名度
- **研究人员**分析 Canton Network 链上数据
