## 概述

CCTools 是面向 Canton Network 生态系统的领先多功能工具平台。它提供你所需的一切，帮你追踪投资组合、发现项目、赚取奖励、监控网络数据，并随时掌握 Canton 生态系统的最新动态。

无论你是 DeFi 用户、验证者，还是刚开始接触 Canton，CCTools 都为你提供一个统一的仪表盘来管理这一切。

## 核心功能

**Portfolio Tracker** - 连接你的钱包，查看完整的 Canton 投资组合，包含实时价格、盈亏、奖励和转账历史。

**Tracker** - Canton party 检查器，用于发现并检查全网的验证者、项目和已验证名称。

**Ecosystem Directory** - 浏览数百个在 Canton Network 上构建的项目，可按类别、角色和状态进行筛选。为你喜欢的项目点赞。

**Canton Map** - 交互式网络图，可视化展示 Canton 生态系统中的 party、项目、验证者及其相互关系。

**Compare** - 并排比较最多 3 个项目；免费版和专业版的上限相同。

**Markets** - 多资产市场，涵盖 DeFi、RWA、稳定币、代币、获取 CC、跨链桥和钱包。

**Earn** - 完成任务、发现机会并参与活动，赚取 XP 并攀登排行榜。

**Academy** - 阅读由团队撰写的关于 Canton 和 CCTools 的精选文章与实操指南。社区投稿尚未开放，投稿编辑器仍在打磨中。

**News** - 聚焦 Canton 的新闻源，配有 LLM 摘要，外加一个由成员投稿组成的社区动态。搜索、筛选并订阅新内容通知。

**Learn Paths** - 多步骤的结构化学习路径，带你逐步了解 Canton、CCTools 及相关主题。

**Rewards Calculator** - 计算作为 App Builder、Validator 或 CC Holder 的潜在奖励。

**Network Stats** - Canton Network 实时指标，含 CC 价格历史与销毁/铸造图表。

**Governance** - 追踪 Super Validator 的投票和治理提案。

**Leaderboard** - 查看你在其他 CCTools 用户中的排名，另有 Validators、Featured Apps 和 Ecosystem 项目的独立榜单。用户榜单可按 XP、推荐数或连续天数排序，XP 排序还可按全部时间、本月或本周筛选。

**Ask Synchro** - 文档内置的 AI 助手，可解答关于 CCTools 功能、钱包、XP、活动和生态系统相关话题的问题。

## 它面向谁？

CCTools 专为以下人群设计：

- **新用户**，首次探索 Canton Network
- **DeFi 用户**，追踪各个 Canton 应用中的投资组合表现
- **社区成员**，通过参与互动赚取 XP 和徽章
- **项目团队**，希望通过赞助列表获得曝光
- **研究人员**，分析 Canton Network 的链上数据
