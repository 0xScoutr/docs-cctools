## 侧边栏导航

左侧边栏是你的主要导航中心。各入口按以下顺序排列，并由细分隔线分组：

- **Overview** - 你的个性化仪表盘
- **Portfolio** - wallet 追踪与盈亏（P&L）
- **Tracker** - 只读查看任意 Canton party ID 或项目，无需登录
- **Ecosystem** - 项目目录、分类筛选和 Compare
- **Canton Map** - 网络拓扑与关系的可视化展示
- **Earn** - 任务、活动和机会
- **Access** - 来自 Canton 项目的邀请码、allowlist 和受限入驻
- **Markets** - DeFi、RWA、Stablecoins、Tokens、Get CC、Bridges 和 Wallets
- **News** - Canton 新闻动态和社区帖子，可按标签筛选
- **Education** - Academy 与 Learn 学习路径
- **Network** - Network stats、Validators、Featured Apps、Governance、Calculator 和 DevTools
- **Leaderboard** - User、Validators、Featured Apps 和 Ecosystem 四个榜单的社区排行

带有子项的入口在悬停时会展开侧边浮层面板。侧边栏默认是一条窄图标栏，悬停时展开：点击顶部一行中位于 logo 和主题切换按钮旁的图钉图标，即可将其永久固定为打开状态。

## 全局搜索

按 Cmd+K（Mac）或 Ctrl+K（Windows）打开全局搜索。结果分为三个板块：

- **Pages** - 特定的页面和功能
- **Projects** - 生态系统中的项目
- **Earn Listings** - 进行中的 Earn 列表和活动

搜索是在 CCTools 上查找任何内容最快捷的方式。文档并未收录在其中：请使用本文档站点的搜索功能。

## Ask Synchro - 文档助手

点击 "Ask Synchro" 按钮（右下角）打开 CCTools 文档助手。Synchro 可以帮助你解决：

- wallet 的设置与管理
- XP 与游戏化系统
- 活动机制与奖励
- 生态系统与市场相关问题

Synchro 的回答直接来源于 CCTools 文档。如需获取最准确的信息，请参阅官方文档。

## 设置与个人资料

使用侧边栏底部区域来：

- 进入 **Settings** 设置账户、通知与外观偏好（社交集成位于 **Profile > Connections**）
- 查看你的 **Profile**，了解你的参与等级和 Pro 状态（如适用）
- 在尚未登录时进行登录
