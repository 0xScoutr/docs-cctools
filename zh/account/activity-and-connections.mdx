活动和连接部分让你可以查看自己的参与历史，并关联外部账户以进行社区参与和投资组合管理。

## 活动

访问 **活动**，在三个标签页中查看你完整的参与历史。

### XP 标签页

你获得的每个 XP 事件都会显示在这里，按从新到旧排序。每条记录显示：

- 获得 XP 的操作（例如，"每日签到"、"为项目点赞"、"项目已批准"）。
- 获得的时间（相对时间，如"2 小时前"，较早的事件则显示确切日期）。
- 以绿色显示的 XP 数量。

顶部的摘要条显示你获得的 XP 事件总数。

### 提交标签页

跟踪你提交的每个项目、机会和编辑建议。每条记录显示：

- 提交的标题。
- 其类型标签（新项目、机会或编辑建议）。
- 提交日期。
- 以彩色徽章显示的当前状态：
  - 绿色"已批准"
  - 琥珀色"待处理"或"需要修改"
  - 红色"已拒绝"

摘要条显示你的提交总数，并按已批准和待处理的数量分类。对于已批准的项目提交，你可以点击箭头图标跳转到项目页面。

### 投票标签页

查看你点赞过的所有项目，按从新到旧排序。每一行显示：

- 项目名称和徽标。
- 其类别（如已设置）。
- 你点赞的时间。
- 一个确认"已点赞"的绿色徽章。
- 指向项目页面的链接。

摘要条显示你点赞过的项目总数。

## 连接

**连接**页面让你可以关联社交账户和钱包，以启用任务验证和跨链投资组合管理。

### 已连接账户

关联你的社交账户，以解锁参与社区驱动功能和任务验证的权限。支持五种提供方：

- **Google**：点击"连接"以使用你的 Google 账户进行身份验证。关联后，你的电子邮件会显示在标签下方。可随时通过断开连接图标解除连接。
- **X (Twitter)**：点击"连接"以关联你的 X 账户。关联后会显示你的用户名（@username）。
- **Discord**：连接你的 Discord 账户以启用社区验证。关联后会显示你的 Discord 用户名。
- **Telegram**：在桌面端，点击"连接"时会出现一个登录小部件。在移动端，你会被重定向到 Telegram 进行身份验证。连接后会显示你的 Telegram 用户名。
- **GitHub**：使用 OAuth 关联你的 GitHub 账户。关联后会显示你的 GitHub 用户名。

对于每个已连接的账户，你会看到一个绿色的"已连接"徽章。点击断开连接图标即可移除该账户。随后，后端会在你下次会话时清除该关联。

### 钱包

关联 Canton 钱包以及跨链 EVM 或 Solana (SVM) 钱包，以汇总你的投资组合。你可以：

- 连接多个钱包：免费版每条链 1 个，Pro 每条链最多 5 个，每条链可指定一个主钱包。
- 直接重命名钱包标签，便于识别。
- 设置主钱包。
- 随时断开钱包连接。

有关完整的钱包设置指南，包括添加钱包和管理标签的分步说明，请参阅 [Adding Wallets](/portfolio/adding-wallets)。
