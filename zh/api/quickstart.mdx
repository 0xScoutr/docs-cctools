## 1. 登录

打开 [cctools.network](https://cctools.network) 并登录（或创建一个账户）。

## 2. 打开开发者面板

前往 [cctools.network/profile/api](https://cctools.network/profile/api)。

## 3. 获取套餐和密钥

密钥需要账户拥有一个套餐。该页面上的套餐面板会显示你可以选择什么：

- **Pro**：[CCTools Pro](https://cctools.network/pro) 订阅包含供个人使用的 API 访问，每个 endpoint 每分钟 60 次请求、每天 1,000 次调用。Pro 卡片会即时授予（**Unlock Pro access**）。
- **试用**：想先试用 API，点击 **Start the trial**。它每个账户限开通一次，面向已连接钱包并通过 CCTools 真人验证的账户，仅供测试，每分钟 60 次请求、每天 1,000 次调用。
- **Data Starter 或 Data Team**：适用于向他人展示数据的产品或服务。点击 **Buy Data Starter** 或 **Buy Data Team**，用 Canton Coin 支付。Data Starter 每分钟 120 次请求、每天 20,000 次调用；Data Team 每分钟 600 次请求，没有每日上限。价格见[套餐与限制](/zh/api/plans)，条款见 [cctools.network/terms/api](https://cctools.network/terms/api)。
- **Validator**：提交你的 Canton 验证者 party ID。每份提交都由人工审核，通常在一个工作日内完成。获批的密钥没有单个密钥的速率限制，并且 12 个月内免费。
- **构建者 / 基金 / 合作伙伴**：填写简短的申请表，并告诉我们你正在构建什么，或者就 Enterprise [联系我们](https://cctools.network/contact)。更高的限额按账户单独商定。

每个 IP 地址每分钟 600 次请求的上限适用于所有套餐。

账户拥有套餐后，点击 **New key**。明文密钥（`cck_…`）只会显示**一次**。请复制并妥善保存：你无法再次查看它，只能吊销它并生成一个新的。

<Warning>
切勿在客户端代码中暴露密钥。请通过你自己控制的服务器代理这些调用。任何拿到你密钥的人都能以你的身份调用 API，直到用满你的速率限制。
</Warning>

## 4. 发起你的第一次调用

```bash
curl -H "X-API-Key: cck_your_key_here" \
  "https://api.cctools.network/api/v1/public/ecosystem/projects?limit=5"
```

你应该会收到一个 JSON 信封：

```json
{
  "data": [ { "slug": "…", "name": "…", "ai_score": 87 } ],
  "pagination": { "limit": 5, "offset": 0, "total": 491 },
  "meta": { "tier": "pro", "rate_limit_remaining": 60, "daily_limit_remaining": 999 }
}
```

就是这样。你可以在 [endpoint 参考](/zh/api/endpoints) 中浏览全部路由，或者在 [cctools.network/api-docs](https://cctools.network/api-docs) 用你的密钥直接在浏览器中调用。

<Tip>
只要带上 `X-API-Key` header，使用 `curl`、`python-requests` 或任何默认客户端进行测试都可以开箱即用。来自工具类客户端的无密钥请求会被拦截，带密钥的请求不会。
</Tip>
