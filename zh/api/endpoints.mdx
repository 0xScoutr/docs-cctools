全部 48 个 endpoint 都位于 `https://api.cctools.network` 下，返回标准的
`{ data, pagination, meta }` 信封结构，并且需要 `X-API-Key` header。唯一的例外是
`/api/v1/public/status`，它无需密钥，直接返回自身的 payload。

列表类 endpoint 接受 `?limit=` 和 `?offset=`。常见形式是默认 50、最大 200，但有几个
列表的上限更低（50 或 100），还有几个完全忽略 `limit`。请读取 `pagination` 中回传的
`limit`，不要凭假设。超出可接受范围的值会被静默地调整为最接近的有效值，而不会返回错误。

在大多数列表中，`pagination.total` 是真实总数。但在 `/news` 和
`/markets/tokens` 中，它只是你这一页拿到的条数，所以请分页直到收到的条目少于你的
`limit`，而不要拿它和 `total` 比较。

<Note>
把 `cck_...` 替换为你在
[/profile/api](https://cctools.network/profile/api) 中的任意一个密钥。
[cctools.network/api-docs](https://cctools.network/api-docs) 提供了带实时发送按钮的
交互式浏览器。
</Note>

<Warning>
**冷缓存。** 大多数由 cron 预热缓存提供的 endpoint 在缓存为空时会返回 `503` 并带上
`warming_up` 代码，而不是返回空内容。请把它当作需要重试，而不是空结果。有三个的行为
不同，在基于它们开发之前值得了解：`/governance` 和 `/network/stats` 会返回 `200`，
字段为 null 或 0；`/featured-apps/{slug}` 会返回 `404`，这与 slug 不存在无法区分。
</Warning>

<Warning>
**除了密钥自身的限制之外，还有一个按 IP 的上限。** 对 `/api/` 的每一次请求，在包括
Validator 在内的所有套餐上，都会计入每个 IP 地址每分钟 600 次请求的上限。持续超限会
升级为对该 IP 的临时封禁，所以看到 `429` 时请退避，不要立即重试。如果你需要更高的
上限来做一次历史回填，请先告诉我们再执行。
</Warning>

<Note>
“用途”列说明该 endpoint 的数据可否用于商业产品（Data 套餐）还是仅供个人使用，“来源”列说明数据来自哪里。各套餐及其限制见 [套餐与限制](/zh/api/plans)。
</Note>

## 生态系统

Projects, categories, rankings, trending.

| Endpoint | 说明 | 用途 | 来源 |
|---|---|---|---|
| `GET /api/v1/public/ecosystem/categories` | List categories with counts | Data 套餐 | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects` | List projects | Data 套餐 | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects/{slug}` | Get project by slug | Data 套餐 | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects/{slug}/analytics` | Engagement analytics for a project | 个人使用 | CCTools engagement analytics |
| `GET /api/v1/public/ecosystem/projects/{slug}/campaigns` | Project campaigns | Data 套餐 | CCTools ecosystem directory |
| `GET /api/v1/public/ecosystem/projects/{slug}/token` | Project token stats | 个人使用 | DexScreener, cached by CCTools |
| `GET /api/v1/public/ecosystem/rankings` | Projects ranked by metric | 个人使用 | CCTools ecosystem directory, ranked by upvotes, views and clicks |
| `GET /api/v1/public/ecosystem/trending` | Top 20 trending projects this epoch | Data 套餐 | CCTools ecosystem directory, scored from upvotes, views and clicks |

```bash
curl -H "X-API-Key: cck_..." \
  "https://api.cctools.network/api/v1/public/ecosystem/categories"
```
