CCTools 公共 API 让你以编程方式只读访问驱动
cctools.network 的同一份 Canton Network 数据：
生态系统目录、赚取活动、排行榜、
公开用户资料、治理、新闻，以及实时网络统计。

## 基础地址

```
https://api.cctools.network
```

需要密钥的 endpoint 都位于 `/api/v1/public/` 前缀之下，并返回 JSON。另有一条路由按次通过 x402 付费、无需密钥，位于 `/api/v1/x402/` 之下：见[通过 x402 按次付费](/zh/api/x402)。

## 认证

除 `/api/v1/public/status` 外，所有 `/api/v1/public/` endpoint 都需要 API 密钥，通过 **`X-API-Key`** header 发送。不存在
`Authorization: Bearer` 方案，携带 Bearer header 的调用会被拒绝。

```bash
curl -H "X-API-Key: cck_your_key_here" \
  "https://api.cctools.network/api/v1/public/network/stats"
```

密钥来自你账户的套餐：见下面的“套餐一览”。
在 [cctools.network/profile/api](https://cctools.network/profile/api) 生成和管理密钥。
完整流程见[认证](/zh/api/authentication)。

## 响应结构

成功的响应都采用同一种结构：

```json
{
  "data": { "...": "..." },
  "pagination": { "limit": 50, "offset": 0, "total": 491 },
  "meta": { "tier": "pro", "rate_limit_remaining": 60, "daily_limit_remaining": 999 }
}
```

- `data`：payload（对象或数组，取决于 endpoint）。
- `pagination`：在列表 endpoint 上出现，其他情况为 `null`。
- `meta.tier`：你的密钥所属套餐：`evaluation`、`pro`、`data`、`data_team`、`validator`，Enterprise 为 `paid`。
- `meta.rate_limit_remaining`：你的每分钟上限。
- `meta.daily_limit_remaining`：按你的套餐每日上限，今天还剩多少次调用；套餐没有每日上限时为 `null`。

错误响应为 `{ "error": "message", "code": "..." }`，HTTP 状态码为
`400`、`401`、`404`、`429` 或 `503`。
带有 `warming_up` 代码的 `503` 表示由 cron 预热的数据集处于冷缓存状态：
请在一分钟后重试，而不要将其视为空结果。

## 套餐一览

密钥拥有创建它的账户的套餐。每分钟限制按每个密钥和 endpoint 计数；每日限制按整个账户在一个 UTC 日内的调用数计数。

| 套餐 | 用途 | 每分钟 | 每天 | 获取方式 |
|---|---|---|---|---|
| **Evaluation** | 仅供测试 | 每分钟 60 次请求 | 每天 1,000 次调用 | 由我们团队按申请签发的密钥 |
| **Pro** | 个人使用 | 每分钟 60 次请求 | 每天 1,000 次调用 | 包含在 [CCTools Pro](https://cctools.network/pro) 中。在 /profile/api 即时自助获取 |
| **Data Starter** | 商业使用，需署名 | 每分钟 120 次请求 | 每天 20,000 次调用 | 在 /profile/api 用 Canton Coin 购买，按月或按年 |
| **Data Team** | 商业使用，需署名 | 每分钟 600 次请求 | 无每日上限 | 在 /profile/api 用 Canton Coin 购买，按月或按年 |
| **Validator** | 按 Development Fund Committee 批准的条件 | 无按密钥限制 | 无每日上限 | 提交 party ID；由人工审核，通常在一个工作日内完成。免费 12 个月 |
| **Enterprise** | 在你的产品内商业使用，按约定的订单 | 无按密钥限制 | 无每日上限 | 联系我们 |

所有套餐（Validator 也不例外）在整个 API 范围内还受到一个上限约束：
每个 IP 地址每分钟 600 次请求。

价格、各套餐允许的密钥数量和完整表格见[套餐与限制](/zh/api/plans)，该页由 API spec 生成。
同样的数字也在 [cctools.network/api-docs](https://cctools.network/api-docs)，
适用于所有套餐的条款在 [cctools.network/terms/api](https://cctools.network/terms/api)。

## 无需密钥，免费使用

以下内容无需密钥，也无需账户，全部由 `https://api.cctools.network` 提供：

- 开放的每日网络记录，位于 `/api/open/network-record/v1/`，以 CC BY 4.0 发布。
- 聚合器读取的数据源，位于 `/api/markets/`。
- 状态 endpoint，`/api/v1/public/status`。
- OpenAPI 文件，`/api/v1/openapi.json`。
- MCP 服务器，`/api/mcp`。

`/api/v1/public/` 下的其他所有内容都需要密钥。
