## 代币经济学

**CC 代币**是 Canton Network 的原生货币。

- **十年发行上限**：1000 亿 CC。Canton 没有固定的最大供应量；CC 按减半计划持续发行，网络统计页面正是以该上限来衡量流通供应量和 FDV。
- **发行**：每个铸币轮次都会铸造 CC，作为超级验证者、验证者和精选应用的奖励，每次铸造的 5% 进入开发基金（CIP-0082）
- **销毁**：验证者购买同步器流量时会销毁 CC，这是 Canton Network 对提交交易收取的费用
- **减半**：铸币奖励按照减半时间表定期减少
