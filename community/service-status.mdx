CCTools aims for 24/7 availability across all platform features. When something isn't working as expected — whether that's slow portfolio data, a news feed that isn't loading, or an unresponsive feature — this page explains where to look and what to do.

## Real-time status dashboard

The CCTools public API has a live status page at **[status.cctools.network](https://status.cctools.network)**. It refreshes automatically every 30 seconds and gives you a granular view of which services are healthy and which are not.

The dashboard shows:

- **Overall system status** — either All systems operational, Degraded performance, or Major outage
- **Per-endpoint health** — status, last check time, HTTP response code, latency, and a 1-hour uptime percentage for each core service
- **Active incidents** — any ongoing issues with a severity level (minor, major, or critical), current status (investigating, identified, monitoring), and which endpoints are affected
- **Recent incident history** — resolved incidents from the past 30 days, so you can see what was recently fixed

Check the status page first any time you encounter unexpected behaviour. If there's a known incident, it will be listed there along with its current status.

## Common issues and quick fixes

**Portfolio data is delayed or stale**

Canton blockchain indexers occasionally run behind, especially during periods of high network activity. This is normal and temporary. Use the **Refresh** button on your portfolio page to trigger a manual sync. If balances are still wrong after a few minutes, try removing and re-adding the affected wallet.

**News feed isn't updating**

The news ingestion pipeline runs every 10 minutes. If the feed looks stale, wait a few minutes and reload the page. If the issue persists beyond 30 minutes, check [status.cctools.network](https://status.cctools.network) for any active incidents affecting the news service.

**Features aren't loading**

If a page or feature isn't responding, check the status dashboard for any active incidents. If the dashboard shows all systems operational but you're still seeing issues, it may be a local network or browser problem — try a hard refresh (Ctrl+Shift+R / Cmd+Shift+R) or a different browser.

## Discord status announcements

For incidents that affect a large portion of users, the CCTools team posts announcements in the **#announcements** and **#status** channels on Discord. If you're experiencing an issue and the status page doesn't yet reflect it, checking Discord is the fastest way to find out if others are affected and whether the team is already investigating.

Join the server at [discord.gg/Pm2YpafyxP](https://discord.gg/Pm2YpafyxP).

## Reporting an issue

If the status page shows everything as healthy but you're still experiencing a problem, please report it:

- **Discord** — Post in **#support** with a description of the issue, what you were trying to do, and any error messages you saw
- **Contact form** — Submit a report at [cctools.network/contact](https://cctools.network/contact) for issues that need a direct response from the team

<Info>
  When reporting an issue, include your browser, operating system, and a description of the steps that led to the problem. Screenshots are especially helpful for UI issues.
</Info>
