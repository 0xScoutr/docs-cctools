## How Referrals Work

Share your unique referral code (format: `CC-XXXXXX`) with friends. When they sign up using your code, the referral enters **pending** status.

The referred user must then complete **all 5 required tasks** to confirm the referral:

1. **Follow @cantontools** on X
2. **Maintain a 2-day daily streak**
3. **Add a wallet** to their portfolio
4. **Upvote 3 ecosystem projects**
5. **Show interest in 3 Earn opportunities**

Each task awards XP. Once all tasks are complete and the referred user reaches **Level 4**, the referral is confirmed.

## XP Rewards

- **Referred user** receives bonus XP immediately when signing up with a code
- **Referrer** receives XP when the referral is fully confirmed (all tasks done + Level 4)

Referral badges are awarded as you reach referral milestones.

## Rules

- You must be **Level 4** or higher to have an active referral code
- The referred user must complete **all 5 tasks** (not just one)
- No self-referrals or fake accounts
- Referral codes cannot be reused by another user

We have anti-abuse systems in place to ensure fair referrals.
