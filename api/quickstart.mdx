## 1. Sign in

Open [cctools.network](https://cctools.network) and sign in (or create an
account).

## 2. Open the developer panel

Go to [cctools.network/profile/api](https://cctools.network/profile/api).

## 3. Get a plan and a key

A key needs a plan on your account. The plan panel on that page shows what you
can take:

- **Pro**: a [CCTools Pro](https://cctools.network/pro) subscription includes
  API access for personal use, at 60 requests per minute for each endpoint and
  1,000 calls per day. The plan panel shows Pro as your plan; press **Set up keys**
  once (an account that had a Free or an evaluation key sees **Upgrade to Pro tier** instead).
- **Evaluation**: to test the API before you buy, ask our team for an
  evaluation key. An account that has never held a plan applies on that page;
  any other account [contacts us](https://cctools.network/contact). It is for
  testing only, at 60 requests per minute and 1,000 calls per day.
- **Data Starter or Data Team**: for a product or service that shows the data to
  others. **Buy Data Starter** or **Buy Data Team** and pay in Canton Coin.
  Data Starter allows 120 requests per minute and 20,000 calls per day; Data
  Team allows 600 requests per minute with no daily cap. Prices are on
  [Plans and limits](/api/plans), and the terms at
  [cctools.network/terms/api](https://cctools.network/terms/api).
- **Validator**: submit your Canton validator party ID. Every submission is
  reviewed by a person, usually within one business day. Approved keys carry no
  per-key rate limit and are free for 12 months.
- **Builder / fund / partner**: fill out the short application and tell us what
  you are building, or [contact us](https://cctools.network/contact) about
  Enterprise. Higher limits are arranged per account.

A ceiling of 600 requests per minute per IP address applies on every plan.

With a plan in place, click **New key**. The cleartext key (`cck_…`) is shown
**once**. Copy it and store it somewhere safe: you can't see it again, only
revoke it and mint a new one.

<Warning>
Never expose a key in client-side code. Proxy calls through a server you
control. Anyone with your key can call the API as you, up to your rate limit.
</Warning>

## 4. Make your first call

```bash
curl -H "X-API-Key: cck_your_key_here" \
  "https://api.cctools.network/api/v1/public/ecosystem/projects?limit=5"
```

You should get back a JSON envelope:

```json
{
  "data": [ { "slug": "…", "name": "…", "ai_score": 87 } ],
  "pagination": { "limit": 5, "offset": 0, "total": 491 },
  "meta": { "tier": "pro", "rate_limit_remaining": 60, "daily_limit_remaining": 999 }
}
```

That's it. Browse every route in the [endpoint reference](/api/endpoints), or run
one against your key in the browser at
[cctools.network/api-docs](https://cctools.network/api-docs).

<Tip>
Testing with `curl`, `python-requests`, or any default client works out of the
box, as long as the `X-API-Key` header is present. Keyless requests from tool
clients are blocked; keyed requests are not.
</Tip>
