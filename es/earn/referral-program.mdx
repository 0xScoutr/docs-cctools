## Cómo funcionan las referencias

Comparta su código de referencia único (formato: `CC-XXXXXX`) con amigos. Cuando se registran usando su código, la referencia ingresa al estado **pendiente**.

Luego, el usuario recomendado debe completar **las 5 tareas requeridas** para confirmar la recomendación:

1. **Sigue a @cantontools** en X
2. **Mantenga una racha diaria de 2 días**
3. **Agregar una billetera** a su cartera
4. **Vota a favor de 3 proyectos de ecosistema**
5. **Muestre interés en 3 oportunidades de ganar**

Cada tarea otorga XP. Una vez que se completan todas las tareas y el usuario recomendado alcanza el **Nivel 4**, se confirma la recomendación.

## Recompensas de XP

- **El usuario recomendado** recibe XP adicional inmediatamente al registrarse con un código
- **Recomendador** recibe XP cuando la recomendación está completamente confirmada (todas las tareas realizadas + Nivel 4)

Las insignias de recomendación se otorgan a medida que alcanzas hitos de recomendación.

## Normas

- Debes tener **Nivel 4** o superior para tener un código de referencia activo
- El usuario recomendado debe completar **las 5 tareas** (no solo una)
- No hay autorreferencias ni cuentas falsas.
- Los códigos de referencia no pueden ser reutilizados por otro usuario

Contamos con sistemas antiabuso para garantizar referencias justas.
