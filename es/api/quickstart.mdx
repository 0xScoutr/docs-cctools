## 1. Inicia sesión

Abre [cctools.network](https://cctools.network) e inicia sesión (o crea una
cuenta).

## 2. Abre el panel de desarrollador

Ve a [cctools.network/profile/api](https://cctools.network/profile/api).

## 3. Consigue un plan y una clave

Una clave necesita un plan en tu cuenta. El panel de planes de esa página muestra
lo que puedes tomar:

- **Pro**: una suscripción a [CCTools Pro](https://cctools.network/pro) incluye
  acceso a la API para uso personal, con 60 solicitudes por minuto en cada
  endpoint y 1.000 llamadas por día. La tarjeta de Pro lo concede al instante
  (**Unlock Pro access**).
- **Prueba**: **Start the trial** si quieres probar primero la API. Se abre una
  sola vez por cuenta a las cuentas con una billetera conectada que superan la
  verificación de persona real de CCTools, solo para pruebas, con 60
  solicitudes por minuto y 1.000 llamadas por día.
- **Data Starter o Data Team**: para un producto o servicio que muestra los datos
  a otras personas. **Buy Data Starter** o **Buy Data Team** y paga en Canton
  Coin. Data Starter permite 120 solicitudes por minuto y 20.000 llamadas por
  día; Data Team permite 600 solicitudes por minuto y no tiene tope diario. Los
  precios están en [Planes y límites](/es/api/plans), y los términos en
  [cctools.network/terms/api](https://cctools.network/terms/api).
- **Validator**: envía el party ID de tu validador de Canton. Cada solicitud de
  clave la revisa una persona, normalmente en un día hábil. Las claves aprobadas
  no tienen límite de solicitudes por clave y son gratuitas durante 12 meses.
- **Builder / fondo / socio**: completa el formulario breve y cuéntanos qué estás
  construyendo, o [contáctanos](https://cctools.network/contact) por Enterprise.
  Los límites más altos se acuerdan por cuenta.

Un tope de 600 solicitudes por minuto por IP se aplica en todos los planes.

Con un plan en tu cuenta, haz clic en **New key**. La clave en texto plano
(`cck_…`) se muestra **una sola vez**. Cópiala y guárdala en un lugar seguro: no
podrás volver a verla, solo revocarla y generar una nueva.

<Warning>
Nunca expongas una clave en código del lado del cliente. Enruta las llamadas por un servidor
que controles. Cualquiera con tu clave puede llamar a la API en tu nombre, hasta tu límite de solicitudes.
</Warning>

## 4. Haz tu primera llamada

```bash
curl -H "X-API-Key: cck_your_key_here" \
  "https://api.cctools.network/api/v1/public/ecosystem/projects?limit=5"
```

Deberías recibir un envoltorio JSON:

```json
{
  "data": [ { "slug": "…", "name": "…", "ai_score": 87 } ],
  "pagination": { "limit": 5, "offset": 0, "total": 491 },
  "meta": { "tier": "pro", "rate_limit_remaining": 60, "daily_limit_remaining": 999 }
}
```

Eso es todo. Explora todas las rutas en la [referencia de endpoints](/es/api/endpoints),
o ejecuta una con tu clave desde el navegador en
[cctools.network/api-docs](https://cctools.network/api-docs).

<Tip>
Probar con `curl`, `python-requests` o cualquier cliente por defecto funciona sin
configuración adicional, siempre que el header `X-API-Key` esté presente. Las solicitudes
sin clave desde clientes de herramientas se bloquean; las solicitudes con clave, no.
</Tip>
