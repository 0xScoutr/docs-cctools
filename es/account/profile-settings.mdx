## Actualiza Tu Perfil

Ve a **Profile** desde la barra lateral y luego selecciona **Identity**. Aquí puedes:

- Cambiar tu nombre para mostrar
- Subir un avatar

El correo electrónico de tu cuenta está en **Settings > Account**, junto con la contraseña y la 2FA.

## Cuentas Conectadas

Puedes conectar cuentas sociales a tu perfil de CCTools para tareas de campaña y verificaciones.

### Conexiones disponibles

- **X (Twitter)** - Necesaria para la insignia X Follower y tareas de campaña como seguir o retuitear
- **Discord** - Se usa para integraciones de campaña y verificación de ingreso al servidor
- **Telegram** - Se usa para integraciones de campaña y verificación de grupo
- **Google** - Método de inicio de sesión alternativo
- **GitHub** - Vincula tu cuenta de GitHub a tu perfil de CCTools

### Administrar conexiones

Ve a **Profile > Connections** para agregar o quitar cuentas sociales. 

- Puedes conectar varias cuentas sociales a un solo perfil de CCTools
- Siempre debes tener al menos un método de inicio de sesión activo (no puedes desconectar tu única identidad)
- Las cuentas conectadas aparecen con su nombre para mostrar o nombre de usuario para que puedas confirmar cuál cuenta está vinculada

## Conexiones de Billetera

Puedes vincular billeteras de blockchain de varias cadenas a tu perfil.

### Cadenas compatibles

- **Canton** - Vincula tu billetera principal de Canton para la verificación. El plan gratuito admite 1 billetera, Pro admite hasta 5
- **EVM** - Ethereum y cadenas compatibles con EVM (Arbitrum, Base, Polygon, etc.)
- **Solana** - Billeteras Solana (SVM), vinculadas mediante verificación de firma

### Administrar billeteras

Ve a **Profile > Connections** para vincular billeteras nuevas o administrar las existentes.

- Establece cualquier billetera vinculada como principal con un solo clic
- Etiqueta las billeteras para llevar el control de varias direcciones
- Desconecta las billeteras que ya no uses
- Cada cadena tiene su propio límite de billeteras según tu plan (plan gratuito: 1 por cadena, plan Pro: hasta 5 por cadena)
- Las conexiones de billetera entre cadenas suman puntaje extra para tu verificación del ecosistema de Canton

## Perfil Público

Cada usuario de CCTools tiene un perfil público en **cctools.network/u/your-username**. Tu perfil público muestra:

- Nombre para mostrar y avatar
- Nivel y título de nivel
- Tus tres insignias más raras, destacadas automáticamente
- Racha actual

Comparte el enlace de tu perfil en redes sociales para mostrar tu participación en el ecosistema de Canton.
