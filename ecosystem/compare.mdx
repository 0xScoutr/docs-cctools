The Compare tool lets you evaluate Canton ecosystem projects head-to-head, surfacing differences in AI scores, activity, community engagement, and transparency in a single view. Instead of clicking between multiple project pages and trying to hold the details in your head, Compare puts everything on one screen so the differences are impossible to miss.

## How to compare projects

<Steps>
  <Step title="Open the Compare page">
    Go to [cctools.network/ecosystem/compare](https://cctools.network/ecosystem/compare).
  </Step>
  <Step title="Add your first project">
    Click **Add Project A** and type a project name in the search box. Select the project from the results to add it to the first column.
  </Step>
  <Step title="Add your second project">
    Click **Add Project B** and repeat the search to populate the second column.
  </Step>
  <Step title="Optionally add a third project">
    Click **Add Project C** to include a third project in the comparison. This is optional — two-project comparisons work just as well.
  </Step>
  <Step title="Review the side-by-side breakdown">
    Scroll through the comparison table to see how each project stacks up across all metrics.
  </Step>
</Steps>

## What you can compare

The comparison view surfaces both high-level and granular data for each project side by side:

<CardGroup cols={2}>
  <Card title="Overall AI Score" icon="star">
    The composite out-of-100 score generated by the CCTools algorithm
  </Card>
  <Card title="Activity Score" icon="activity">
    On-chain and off-chain activity signals — transactions, deployments, and updates
  </Card>
  <Card title="Maturity Score" icon="shield-check">
    How established the project is — age, stability, and track record
  </Card>
  <Card title="Community Score" icon="users">
    Social following, engagement, and community growth momentum
  </Card>
  <Card title="Transparency Score" icon="eye">
    Openness of team identity, code, roadmap, and governance
  </Card>
  <Card title="Documentation Score" icon="book-open">
    Quality and completeness of technical and user-facing documentation
  </Card>
</CardGroup>

In addition to the five algorithm dimensions, the comparison also shows each project's:

- **Status** — Live or Building
- **Category** — DEX, Wallet, Payments, Exchange, Tokenized Assets, RWA, or Infrastructure
- **Upvotes** — total community upvotes received
- **Views** — total profile views on CCTools

## Using Compare from a project page

You don't have to start from the Compare page. On any project's detail page, click the **Compare** button to add that project directly to an active comparison. If you haven't started a comparison yet, clicking Compare on a project page opens the Compare tool with that project already loaded in the first slot.

This makes it easy to compare as you browse — open a project you're interested in, click Compare, then add a second project to see how they measure up.

<Tip>
  Use Compare when deciding which DEX to use for swapping CC, or when evaluating which wallet app best fits your needs. The side-by-side score breakdown makes it easy to spot meaningful differences that aren't obvious from project cards alone.
</Tip>
