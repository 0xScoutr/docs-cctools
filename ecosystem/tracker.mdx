The tracker section of the Ecosystem covers two directories — **Validators** and **App Addresses** — giving you a live view of all active Canton Network participants. Whether you want to understand who secures the network, find a validator to host your wallet, or trace on-chain app deployments back to the projects behind them, these two pages give you that full picture in one place.

## Validators

Visit [cctools.network/validators](https://cctools.network/validators) to see every validator currently operating on the Canton Network.

Validators are the backbone of Canton — they run the infrastructure that processes transactions, maintain ledger consensus, and participate in governance decisions that shape how the network evolves. In return for this work, validators earn CC rewards proportional to their activity and stake.

The Validators page lists all active validators with the following details:

- **Validator name and identity** — the registered name and on-chain party ID
- **Role** — Super Validator or regular Validator
- **Ecosystem link** — whether the validator is associated with a known Canton project in the CCTools directory

**Filters** let you narrow the list by:

- **Role** — filter to show only Super Validators, only regular Validators, or all
- **Ecosystem link** — show only validators linked to a project, or only standalone validators with no project affiliation

## Super Validators

Super Validators are a distinct class of validator with elevated responsibilities on the Canton Network. Beyond running standard validation infrastructure, Super Validators take on additional governance duties:

- **Price consensus rounds** — participating in the collective determination of on-chain price feeds and reference rates
- **Network configuration changes** — voting on protocol upgrades, fee structures, and other network parameter updates
- **Governance proposals** — sponsoring and ratifying changes that affect all Canton Network participants

Super Validators are typically major financial institutions with significant Canton Network involvement. On the Validators page, Super Validators are clearly marked and can be filtered to a separate view.

## App Addresses

Visit [cctools.network/apps](https://cctools.network/apps) to browse all on-chain addresses linked to Canton ecosystem applications.

While the Validators page covers infrastructure, App Addresses covers the smart contract layer — the on-chain deployments that power wallets, exchanges, DeFi protocols, and other Canton apps. Each row in the directory represents a Canton party address that has been identified as belonging to an ecosystem project.

You can filter by:

- **Ecosystem link status** — show only addresses that are linked to a named project in the CCTools directory, or show unlinked addresses that have been flagged as active but not yet identified

Use App Addresses to verify that a smart contract or on-chain app you're interacting with is actually the one it claims to be, by cross-referencing the address against its linked project profile.

## Submitting a validator

Validators that aren't yet listed in the CCTools directory can apply to be added. Use the **Submit** form on the Validators page to request a listing. The CCTools team will review the submission and reach out if additional information is needed.

<Info>
  Validator data is sourced directly from the Canton Network and updated continuously. Role assignments, addresses, and activity metrics all reflect the live state of the network.
</Info>
